# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 2.0.x   | :white_check_mark: |
| < 2.0   | :x:                |

## Reporting a Vulnerability

We take the security of this project seriously. If you discover a security vulnerability, please do NOT file a public issue.

Instead, please send an advisory report to the maintainer via GitHub Security Advisories or email:
- **Maintainer:** [Vani Mendiratta](https://github.com/vanimendiratta)
- **Email:** Report via GitHub profile contact

Please provide:
1. Description of the vulnerability.
2. Steps or proof-of-concept to reproduce the behavior.
3. Potential impact.

We will review the report promptly and coordinate a patch and disclosure timeline.
